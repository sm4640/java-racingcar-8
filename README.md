# java-racingcar-precourse

## 기능 목록
- 사용자 행위 안내 및 입출력 처리 controller
- 자동차 클래스 생성(이름, 거리, 이름유효성 판단, 이동)
- 레이싱게임 클래스 생성(자동차 리스트, 라운드 진행, 라운드 현황 출력, 우승자 판단)
- 자동차 이름 설정 기준(5글자 이하)에 맞게 split
- 자동차들의 이동 여부에 따른 현재 이동 거리 업데이트
- 자동차들의 차수별 실행 결과 출력
- 최종 우승자 전달
- 전체 로직 통합

## 테스트 코드 상황 상정
- 자동차 이름이 5글자를 초과하면 예외 발생
- 자동차 이름이 비어있는 경우 예외 발생
- 랜덤값이 4 이상일 때 distance가 1 증가해야 됨
- 랜덤값이 4 미만일 때 distance가 바뀌면 안 됨
- 가장 멀리간 사람이 우승자이며, 동점자까지 우승자
- setGame은 이름 문자열을 입력받아서 ','기준으로 공백제거 후 Car객체 리스트를 생성함

## 중점적으로 고려한 점
- 절차지향적인 코드를 먼저 짠 후, 객체지향적으로 코드를 변형하기 위해 두 가지 클래스를 생성함
- 단위테스트를 위한 함수의 SRP 분리 기준에 대한 고민을 함
- 리스트나 배열 같은 자료구조를 순회할 일이 있을 때 stream이나 map 같은 java에서 지원하는 api를 사용함

## 파일 구조
- RacingCarController(controller): 사용자 입력 -> 서비스 호출 -> 결과 출력으로써 UI 관련 담당을 함
- Car(domain): 자동차의 이름, 이동 거리, 이름 유효성 검사, 이동 등의 변수와 기능을 갖는 클래스
- RacingGame(domain): 자동차 리스트, 라운드 진행, 라운드 현황 출력, 우승자 판단 등의 변수와 기능을 갖는 클래스
- RacingCarService(service): setGame으로 문자열 -> 자동차 리스트, runGame으로 라운드 진행, 현황 출력 및 우승자 판단
